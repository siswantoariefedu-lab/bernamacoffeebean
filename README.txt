# BERNAMA COFFEE — Website UAS

Website single-page untuk BERNAMA COFFEE, berdasarkan proposal business:
"Nusantara Roasted Beans Explorer".

## Cara menjalankan
1. Buka folder ini.
2. Double-click `index.html`, atau buka dengan browser.
3. Tidak membutuhkan server untuk preview dasar.

## Struktur
- `index.html` — struktur halaman
- `style.css` — desain responsive
- `script.js` — katalog/filter Explorer Box/form demo
- `assets/` — visual yang diambil dari proposal

## Catatan
Form kontak masih berupa demo. Proposal tidak mencantumkan nomor WhatsApp, email, atau handle media sosial, sehingga tidak dibuatkan kontak palsu. Setelah akun bisnis siap, tombol/form dapat dihubungkan ke WhatsApp, Instagram, TikTok, atau marketplace.
